Task Management Backend System

README

Task Management

A production-oriented REST API backend for managing users and their tasks, built with FastAPI, PostgreSQL, SQLAlchemy and JWT-based authentication.

The project focuses on clean backend architecture, authentication, authorization, database interaction, API design and maintainable code organization.

Features

  • User registration and login
  • JWT authentication and protected routes
  • Password hashing and verification
  • Role-based access control
  • User-specific task management and ownership validation
  • CRUD operations for tasks
  • PostgreSQL + SQLAlchemy ORM
  • Pydantic validation and environment configuration
  • Postman API testing
  • Modular backend architecture

Tech Stack

Backend: Python, FastAPI, SQLAlchemy, Pydantic
Database: PostgreSQL, Supabase PostgreSQL
Authentication: JWT, OAuth2 password flow, password hashing
Tools: Git, GitHub, Postman, Alembic

Architecture

The backend follows a layered architecture that separates API handling, authentication, business logic, database operations and validation.

Personal Digital Command Centre

A personal productivity and management system designed to bring tasks, notes, files and personal data into one centralized digital workspace.

The project is being developed as a modular full-stack application with a focus on practical backend engineering, file management, API architecture and a scalable foundation for future features.

One Application
      │
      ├── Tasks
      ├── Notes
      ├── Files
      └── Personal Data
Architecture

The application uses a simple layered architecture. The frontend communicates with a FastAPI backend through HTTP APIs; services handle application logic and the backend communicates with the database and filesystem when required.
