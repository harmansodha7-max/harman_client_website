# Harman Sodha — Personal Profile Website

A clean, responsive personal profile website built with plain HTML, CSS and JavaScript.

## Project structure

```text
harman-profile-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Run locally

No installation is required.

1. Open `index.html` in a browser.
2. Check the navigation, sections and contact links.
3. For a more realistic local server, use VS Code Live Server later when you have a laptop.

## Before publishing

Check:
- Name and contact details
- Skills are accurate
- Project descriptions are accurate
- Mobile layout
- Email and phone links
- No placeholder information remains

## Publishing

Do NOT publish this project automatically. First learn the publishing process, then choose a method such as GitHub Pages or another static hosting service.

## Google Drive folder

A Google Drive folder is simply an online folder where you keep the files/links related to the internship task. If the organizers provide a specific Drive folder/link, use that folder. If they ask you to create your own folder, create one such as:

`AI Web Development Internship / Task 1 - Personal Profile Website`

You can keep:
- Website ZIP
- Live website link (a Google Doc or text file)
- LinkedIn/social-media screenshot
- Any other required files

## Mode pages

- `index.html` — Home (existing home content preserved)
- `projects.html` — Projects mode with Task Management Backend System and Personal Digital Command Centre
- `build.html` — Build mode with a local access gate before opening the official Wix AI Website Builder
- `book.html` — Book mode placeholder, ready for future booking features
